Scope

  OpenCode node target. Chat identity comes from its existing full scoped
  status read, never the narrow light heartbeat or an alias guess.
- Explicit Read/Refresh status, independent of message reads. No eager control
  polling or new first-paint dependency. This is not a terminal/TUI mirror.
- Button requires affirmative actual runtime capability and a locally fresh
  read (<30s). Fixed state/background operations only, expected original
  session and Bridge-handle binding on every mutation.
- Exactly one enqueue. Subsequent polling only reads that request receipt.
  Unknown write/ACK, missing receipt or invalid response never auto-resubmits.
  An unknown outcome locks this view's mutation button; read-only refresh
  cannot unlock it or re-enqueue the mutation.
- request_processed does not claim that a tool moved to the background.
  already_idle is an explicit no-op. Old Hub/access/binding errors are visible.
- Component key includes Hub/token/network/node/session to isolate navigation.
- No lifecycle, model selection, Hub implementation or release changes.

# Agent Network 0.2.136

## 更新内容

- 任务看板支持打开卡片详情，并明确选择需求池、进行中或完成状态。保存失败会在对应卡片提示，可重试。
- 在卡片详情中选择人类或 Agent 作为负责人、添加参与人；绑定使用稳定身份，而不是显示名。
- 桌面内置 Hub 升级至 0.9.0-preview.64，包含按网络隔离的需求池、GitHub issue 关联与人员绑定接口。
- 连接旧远端 Hub 时，缺少对应接口会提示升级，不回退为本机另存数据。

## 本版边界

- 选择 Agent 为负责人不会自动派发执行任务；看板卡片不等于节点正在执行的任务。
- 新建表单仍使用旧节点 alias 字段；稳定负责人请在详情中绑定。未绑定时卡片可能显示“未分配”。
- 多网络管理员的人员列表网络选择仍待修正；本版不宣称该场景已支持。
- 发布客户端不会自动升级远端生产 Hub。Android/iOS 未随本次桌面构建发布。

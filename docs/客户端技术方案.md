# Agent Network 客户端技术方案

> 目标：**一份 TypeScript 代码，吃下 Android / iOS / Mac / Windows / Web 全部端。**
> 产品基线：掏出手机（或打开电脑）30 秒完成一次督办。
> 最后更新：2026-06-12（v0.1.25 / Tauri 0.2.0）

## 1. 总体架构

```
                    ┌─────────────────────────────┐
                    │   React Native + TypeScript  │
                    │   (Expo SDK 56, 一份代码)     │
                    └──────────────┬──────────────┘
              ┌────────────────────┼────────────────────┐
              ▼                    ▼                     ▼
      原生渲染 (RN)        react-native-web 导出      react-native-web
              │                    │                     │
        ┌─────┴─────┐        ┌─────┴─────┐         ┌─────┴─────┐
        ▼           ▼        ▼           ▼         ▼
     Android      iOS      Mac        Windows     Web 浏览器
     (APK)     (TestFlight) └─ Tauri 2 壳 ─┘      (静态托管)
```

- **界面层**：React Native 组件 + TypeScript。手机上渲染成原生控件（非 WebView，原生滑动/动画手感）；桌面和 Web 通过 `react-native-web` 把同一批组件渲染成 DOM。
- **壳层（桌面）**：Tauri 2（Rust + 系统 WebView）。Mac 用 WKWebView、Windows 用 WebView2，不内置 Chromium，安装包 ~6MB（曾用 Elec­tron 方案为 ~95MB，已切换）。
- **数据层**：全部端直连 CommHub REST API（`https://<hub-domain>`），登录 token 各端安全存储。

## 3. 桌面端关键设计：CORS 与 fetch

Hub 不返回 CORS 头；桌面 WebView 强制同源策略，页面直接 `fetch` 跨域会被拦。

解法：应用启动时检测 Tauri 环境，把 `globalThis.fetch` 替换为 `@tauri-apps/plugin-http` 的 fetch —— 请求走 Rust 侧发出，不受浏览器 CORS 限制，业务代码零改动：

```ts
if ((globalThis as any).__TAURI_INTERNALS__) {
  import('@tauri-apps/plugin-http').then(m => {
    (globalThis as any).fetch = m.fetch;
  });
}
```

权限收敛在 `src-tauri/capabilities/default.json`（仅 http/https）。

## 4. 构建与发布管线

### Android（已跑通）
本机：`expo export` 回归验证 → `gradlew assembleRelease`（arm64）→ APK 直发。
每次发版前全量回归（7 阶段，含真实发送回路 + 附件字节级校验），不过不发。

### 桌面（已跑通）
GitHub Actions `desktop-tauri.yml`（macos-14 runner）：
`npm ci → expo export web → rust toolchain + cache → tauri icon → tauri build` → 产物 .dmg/.app。
Linux 本机无法交叉编译 Rust darwin 目标，所以桌面包统一走 CI。
Windows：同 workflow 加 `windows-latest` matrix 即得 .msi。

### iOS（规划）
同一条 GitHub Actions（mac runner）→ `expo prebuild -p ios` + `xcodebuild`。
**硬门槛：Apple Developer Program（$99/年）**，否则无法装到真机。

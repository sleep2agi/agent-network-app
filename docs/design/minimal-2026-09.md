# 桌面端极简风(2026-09)

来源:owner 2026-09-24「桌面端的 UI/UX 设计你看着弄成极简风，用你的审美升级一下」。此前多次反馈的「丑」集中在:粗黑图标、胶囊/描边太多、深色下的白条。

## 原则

1. **靠底色分层,不靠边框。** 边框只用来分区(面板之间)和表达可点性(输入框)或语义(警示卡);信息卡、聊天气泡、列表行不描边。
2. **一个强调色,且只在「这是可操作的/这是当前位置」时出现。** 二级导航、筛选、选中行一律用中性灰阶;强调色留给最左侧 rail、主按钮、链接。
3. **字重最重 600。** 名字/标题 600,正文 400,次要信息靠颜色(textSecondary / textMuted)而不是靠变细变小。
4. **不用装饰性投影与发光。** 悬停只换一档底色;浮层(右键菜单等)保留投影,因为它确实浮在上面。
5. **所有文字 ≥ 4.5:1**,包括时间戳和提示(旧深色 `textMuted` 只有 2.6:1)。

状态色(running / failed / blocked / broadcast / rest)未改。

### 刻度

- 间距(沿用):4 / 8 / 12 / 16 / 24。
- 圆角:`radius.sm 6`(按钮、chip、输入)· `radius.md 10`(卡片、列表行)· `radius.lg 14`(气泡)· `pill 999`。
- 字号:`type.caption 11` · `small 12` · `body 14` · `title 16` · `heading 20`。
- 字重:`weight.regular 400` · `medium 500` · `strong 600`(上限)。
- 图标:沿用 Ionicons 描边款;激活态实心;尺寸 17–24,不用粗黑填充块。

## 各界面:改了什么、为什么

| 界面 | 之前 | 之后 |
|---|---|---|
| 聊天 | 每条消息一个描边框;每条回复下一条灰底引用块;BTW 是强调色描边胶囊;置顶按钮带框 | 气泡无边框,发出 rowActive / 回复 card;引用改左侧 2px 细线 + 次要色小字;BTW 次要色文字;置顶未开时无底无框 |
| 会话列表 | 深色下每行是一张卡;悬停有投影,头像有青色发光;浅色专用 hex 字面量 | 两种主题都平铺;悬停 rowHover、选中 rowActive;无投影无发光;全部走 token |
| 任务 | 筛选是描边胶囊,选中强调色描边+淡底;每条任务描边卡 | 筛选是分段标签(选中一档中性底色 + 正文色);任务卡无边框 |
| 服务器 / 新建节点 / daemon 选择 | 信息卡描边;二级导航选中是青色块 | 信息卡无边框(警示卡与输入框保留);二级导航选中改中性 rowActive |
| 设置 | 分类选中是青色块、悬停用卡片色 | 选中 rowActive、悬停 rowHover |
| 全局 | 53 处 700/800 粗体 | 最重 600 |

## 没做的(刻意)

- 不改文案、不改交互、不改布局结构;每个既有测试保持通过。
- 不做全仓圆角/字号批量替换:其中不少是圆点/头像(圆角=半径),盲换会把圆变方。新 token 供之后逐个界面迁移使用。
- 托盘面板未在 web 导出里渲染(它是独立的 Tauri 窗口),本次未改其样式。

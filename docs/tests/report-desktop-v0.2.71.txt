Desktop v0.2.71 release-candidate report

- Base: main after app#312 + app#313 (0.2.70 + per-message time + mobile tables)

- Why: Vincent 2026-09-16/17 (Android screenshots): 「每条消息都展示下时间吧」 and 「手机端的那个表格显示还是很有问题」.

Changes

  per row (header: value) and ≤2-column tables use flexible column widths; web/desktop keep the scrollable grid.
- Bump the desktop application consistently to 0.2.71 (9 pinned stamps + updater release notes).
- Bundled local Hub pin unchanged.

A. 改动(#360)
--------------------------------------------------------------------------------
  节点列表新增「新消息」组(src/agents-list.ts buildSections),位于「置顶」之上,只在有内容时显示。
  未读 > 0 的会话都搬进这一组(原分组不再重复显示),按最近一条消息时间排,新的在前;读完(未读 → 0)
  后回到原分组。手动置顶的节点有未读时进「新消息」,读完回「置顶」。
  未读数与菜单栏角标同源:托盘与列表都调用 src/agent-unread-counts.ts 的 agentUnreadCounts。
  有搜索词时不浮动,结果与改动前逐项相同;指针在行间移动或列表滚动时分组先沿用上一份输入,停手 1.2 秒后再更新。
  0.2.94 版本号提交之后 main 上只合入了 #360 这一个 PR。

Packaged local Hub smoke gate
Date: 2026-08-24

Scope
- Hidden packaged-binary smoke entrypoint starts the bundled CommHub.
- It authenticates through the generated local session and calls the public
  /api/auth/me and /api/status endpoints.
- It stops and restarts the Hub, then verifies the endpoint, profile, token,
  and SQLite database persist.
- The desktop release workflow runs this entrypoint with an isolated home on
  both macOS and Windows before signing and publishing.
- Workflow output is checked for known credential markers.

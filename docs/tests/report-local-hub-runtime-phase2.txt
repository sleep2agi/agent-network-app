Security/storage assertions
- Bind address is fixed to 127.0.0.1.
- Port is selected only from 9200..9299; an occupied port is never killed.
- Bootstrap password is randomly generated and saved only via native keyring.
- Token is saved through the existing native profile credential store.
- Child environment removes development-open and legacy master-token variables.
- Logs rotate at 2 MiB and retain one previous file.
- Local profile cannot be removed through ordinary account removal.
- Supervisor retries unexpected exits with finite capped exponential backoff.
- A live but unhealthy lock owner blocks duplicate startup; only a dead PID is
  treated as a stale lock.
- Settings can create a stopped-data backup; destructive deletion requires
  typed confirmation, creates a backup first, and leaves remote profiles intact.
- Unix shutdown sends SIGTERM and falls back to forced termination only after 2s.
- A pinned Hub version change snapshots the stopped data directory before
  launch; health/bootstrap failure restores both the old data and old config.

desktop v0.2.115 — 宽屏列表「更紧凑」+ 修复发送中卡住 + 流式语音输入
================================================================================

A. 本版内容(0.2.114 版本号提交 #415 之后 main 上合入的 PR + 本 PR)
--------------------------------------------------------------------------------
  #416 界面密度新增「更紧凑」档位,安卓宽屏(折叠屏展开)默认使用:左侧列表头像和字号更小,聊天文字不变;
       修复发送途中聊天面板重挂(切换对话)后,消息一直显示「发送中…」并出现重复。
  #418 语音输入升级:流式识别(边说边出字);输入框左侧切换语音/键盘,微信式「按住 说话」大按钮,
       按下震动,上滑取消;语音设置简化为默认一个 API Key(新版火山控制台),可选「流式 / 极速版」,
       流式未开通时自动退回极速版。新增原生依赖 expo-haptics ~56.0.3。
  本 PR(版本号)
       版本号 8 个文件 → 0.2.115,android.versionCode 2114 → 2115;Cargo.lock 只改根包一段。
       release-desktop-auto-update.yml 加 What's new in 0.2.115(含 #416、#418)。

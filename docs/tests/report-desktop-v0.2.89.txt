desktop v0.2.89 — 规则文件 阅读/编辑 + 全屏目录 + 刷新不再冲掉未保存编辑
================================================================================

来源:Vincent 2026-09-24「这个规则文件也太少了」(48 KB AGENTS.md 挤在约 8 行的等宽框里);发版指令经协调方转达。

A. 阅读 / 编辑 切换(#345)
--------------------------------------------------------------------------------
  默认「阅读」:用聊天同款 markdown 渲染(标题/列表/代码块/表格/引用),填满剩余高度、框内滚动。
  「编辑」为原等宽编辑器 + 重新读取 / 保存。两种模式共用一份草稿,有未保存改动时显示「未保存」。

B. 全屏 + 目录(#345)
--------------------------------------------------------------------------------
  应用内全屏浮层(非系统全屏),左侧 h1–h3 目录点击跳转;代码块里的 # 不算标题。Esc / 退出全屏 关闭,焦点回到「全屏」按钮。

C. 修复:定时刷新冲掉未保存编辑(#345)
--------------------------------------------------------------------------------
  首次读取原先绑在每次刷新都会重建的对象上,导致页面刷新即重读并覆盖草稿;改为按 服务器/网络/节点 键读取一次。
  测试环境实测每次进入节点页的读取次数 2 → 1;20 s 定时刷新后草稿仍在。

D. 验证边界(如实)
--------------------------------------------------------------------------------
  本机 Linux 跑不了 Tauri 壳;界面验证为 web 导出 + Playwright(Chromium,42 KB CLAUDE.md,亮/暗 × 两种窗口尺寸)。Mac / Windows 真机外观以发版后实际截图为准。

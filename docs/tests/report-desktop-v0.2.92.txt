desktop v0.2.92 — 菜单栏未读数字与面板一致
================================================================================

来源:Vincent 2026-09-25 反馈——菜单栏图标显示「1」,点开面板却是「没有未读消息」。

A. 根因与修复(#351)
--------------------------------------------------------------------------------
  未读清零时 src-tauri/src/tray.rs 调 set_title(None);macOS 上 tray-icon 0.24.2 会忽略 None 标题,
  旧的「1」留在菜单栏。改为始终传 Some(..),清零时传 Some("")。
  同类另两处:面板列表截到 20 行而总数不截(数字 > 可见行)→ 不再截断;
  推送未成功就记为已发送 → 一次失败后不再重推 → 改为成功后才记,并在主窗口获得焦点/可见时重推。

B. 验证边界(如实)
--------------------------------------------------------------------------------
  tray-badge-consistency.test.ts 13/13(含 500 个随机状态:数字 == 面板行数之和);npm test 124/124;
  tsc 206(基线 205,多出的一条是新测试文件的 node:fs 导入,源码 0 新增)。
  PR CI 不编译整个 Rust crate;本版发版构建是 tray.rs 改动的首次完整编译。
  菜单栏是 macOS 原生控件,Linux 上无法截图——以发版后 Mac 真机确认为准。

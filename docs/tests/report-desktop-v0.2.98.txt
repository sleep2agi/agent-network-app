desktop v0.2.98 — 安卓折叠屏/平板双栏布局
================================================================================

来源:Vincent 09-25「小米有个折叠屏…它是非常宽了…给你做一个版本出来」。

A. 本版内容(0.2.97 版本号提交 #368 之后 main 上合入的全部 PR,共 1 个)
--------------------------------------------------------------------------------
  #369 安卓:窗口宽度 ≥ 700 dp(展开的折叠屏内屏 / 平板)时显示「列表 + 详情」双栏:
       左边节点列表(含「新消息」分组,选中行高亮),右边聊天或节点详情(各标签页)。
       折叠/展开实时切换,保留当前对话、节点标签页和未发送的草稿。
       < 700 dp(折叠后的外屏、所有手机)仍是原来的手机界面;桌面端判据仍是 tauri && width >= 860。

B. 验证边界(如实)
--------------------------------------------------------------------------------
  #369 自测见其 PR 正文:wide-layout.test.ts 96 项、layout-handoff.test.ts 9 项、
  wide-layout-wiring.test.ts 21 项,15 个手工变异全红;web 导出 + 安卓 UA 的 Playwright
  在 392×860 ⇄ 880×780 间切换 21 项 e2e 通过。开发机没有安卓模拟器,
  真机(折叠屏)表现以发版后实际使用为准;两块屏密度不同的设备上折叠会重建 Activity、导航会重置(未处理)。
  本 PR 只改版本号(8 个文件)与发版说明;app.json 不带 android.versionCode(历次版本号提交也没有)。
  Cargo.toml / Cargo.lock 改动会触发 #364 的 rust-check。

Scope: list table header/cells + width model on the #513 field preference +
「恢复默认列宽」 in 字段配置. No Hub changes, no version bump, no release.

Design: drag grows the table (option a, like Feishu/Notion). Columns keep their
own widths and the table scrolls horizontally inside its card; neighbours never
shrink, so resizing one column never silently truncates another. The title keeps
its old behaviour (fills spare card width) until it is dragged; the drag starts
from the rendered width, so a stretched title grows by exactly the drag delta.
Min width: 标题 160px, others 64px. Double-click a handle resets that column;
「恢复默认」 resets fields and widths, 「恢复默认列宽」 resets only widths.
Widths are stored as `width` on each entry of `task_list_fields_v1` (same key,
same try/catch storage path as #513), so hidden or reordered columns keep them;
old saved preferences without widths load unchanged. Handles only render for
pointer UI (touch tables keep native horizontal scrolling).

desktop v0.2.143 — 任务管理增强、手机底部导航「任务」、弱网不再误报断开
================================================================================

A. 本版内容(0.2.142 版本号提交 #500 之后 main 上合入的 PR + 本 PR)
--------------------------------------------------------------------------------
  #499 任务管理:负责人(人)与负责 Agent 分开;描述支持 Markdown;子任务清单(勾选、增删、桌面拖动排序),
       卡片显示进度;项目(左侧按项目筛选、彩色标签、项目管理);预计完成日历选择、精确到秒;参与人头像。
       需要 Hub 支持新字段(sleep2agi/agent-network#2076,生产 Hub 已升 0.9.0-preview.66);
       旧 Hub 上这些区块隐藏并提示升级,负责人退回单选。
  #502 任务描述可粘贴 / 拖入图片(Hub 无需改动)。
  #503 弱网:单轮失败不再算断开,慢时提示「连接较慢」,连续失败 10 秒以上才算断开;任务页离线显示缓存和「重试」。
  #501 安卓手机底部导航「服务器」换成「任务」,服务器移到设置最上面。
  #493 节点页「运行日志」(节点自己的 agent-node 运行日志,节点侧脱敏)。
  本 PR(版本号)
       版本号 8 个文件 0.2.142 → 0.2.143,android.versionCode 2142 → 2143;Cargo.lock 只改根包一段。
       release-desktop-auto-update.yml 加 What's new in 0.2.143。

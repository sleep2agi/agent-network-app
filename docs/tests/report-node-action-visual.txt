Observed problem
----------------
Desktop 0.2.33-1 rendered restart, stop and delete as three oversized,
high-saturation primary buttons. Delete changed only its text colour, leaving
the same cyan fill and therefore the same visual weight as ordinary actions.

Implemented hierarchy
---------------------
- Restart: compact neutral outline.
- Stop: compact amber caution outline.
- Delete: compact red destructive outline and exact-alias confirmation remains.
- All three are 34px high with a 92px minimum width, wrap on narrow layouts,
  and expose hover, pressed, keyboard-focus and accessibility states.
- The semantic colour resolver is palette-driven and verified independently
  against both the dark and light palettes. No action uses the primary accent
  as an opaque fill.

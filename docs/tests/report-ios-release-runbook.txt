iOS release runbook and workflow contract
==========================================

- The runbook documents GitHub-hosted and remote/self-hosted Mac release paths.
- GitHub Actions uses the protected `macos-signing` environment and App Store
  Connect API-key authentication.
- `EXPO_USE_PRECOMPILED_MODULES=false` keeps native modules built from checkout.
- `github.run_number` supplies a unique numeric `CFBundleVersion`.
- The workflow pins Xcode 26.2 and fails early unless Swift 6.2 is active.
- CI creates an ephemeral Apple Distribution identity and IOS_APP_STORE profile
  through the official API, signs manually, and then fails closed unless the
  archive has no registered devices or get-task-allow.
- The IPA artifact gate precedes the optional TestFlight upload.
- The remote-Mac section documents a temporary keychain without exposing any
  repository credential values.

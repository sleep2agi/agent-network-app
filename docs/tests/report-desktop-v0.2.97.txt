A. 本版内容(0.2.96 版本号提交 #363 之后 main 上合入的全部 PR,共 4 个)
--------------------------------------------------------------------------------
  #367 规则文件查找/替换:⌘F(macOS)/ Ctrl+F(Windows/Linux)在「阅读」「编辑」「全屏」里都能用;
       高亮所有匹配、显示 n/N、回车/方向键跳转;「编辑」里「替换」「全部替换」只改草稿,保存才写回节点。
  #366 规则文件读取不再一直转圈:响应体卡住有硬上限,独立兜底计时器 90 s;内容过期(content_purged)、
       done 但没有 content、request_not_found、认不出的状态都退出加载态并说明原因,
       不再把空串当文件内容放进编辑器。
  #365 新建节点:Grok 默认创建 grok-build-acp;共存模式(grok-build-cli)收到 Grok 下的「高级」里,
       标「实验性」并提前显示限制。已有共存节点不受影响(runtime id 不变)。
  #364 CI:改到 src-tauri 的 PR 会编译并测试 Rust(不影响用户可见行为,不写进发版说明)。

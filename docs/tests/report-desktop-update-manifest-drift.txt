Problem
-------
The Tauri release and the deployed updater endpoint carry separate latest.json
copies. Formatting differences are harmless, but a semantic drift can send a
client a signature or asset URL different from the generated release metadata.

Guard
-----
- Reads the deployed manifest and derives its exact desktop-v<version> tag.
- Resolves that published GitHub release and its latest.json asset.
- Rejects a draft, missing asset, malformed JSON/content type, or invalid
  version before comparison.
- Recursively canonicalizes object keys while preserving array order, then
  compares every JSON field.
- Runs manually after a deployment and automatically every six hours with
  contents:read only.

Current live evidence
---------------------
Release asset, deployed endpoint, and docs-site source differ in bytes because
of formatting, but all three canonical JSON documents match. The online value
is version 0.2.33-1 with five signed platform entries.

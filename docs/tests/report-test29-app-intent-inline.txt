## 行为事实

1. selectOpenIntents 纯函数：delivered 恒在途（等节点回执）；pending 仅
   expires_at > now 在途——镜像 Hub expireOpenIntents 判定，过期死意向不锁
   按钮；applied/rejected/expired 终态不锁行；同计划多条取 created_at 最新；
   键 `${node_id}:${schedule_id}`。五条功能断言逐一钉死。
2. 节点计划 tab 每轮只为「有 editable 条目」的节点拉意向记录
   （GET /api/nodes/:id/external-schedule-edits，owner 通道）；非 owner 的
   403（node_owner_required）逐节点静默吞掉——代价只是该节点无徽标，
   不产生页面级报错。
3. 行内徽标「意向在途（待节点领取/节点已领取）：停用 / cron → …」，
   启停与改时间两个按钮同时置灰（断言计数 disabled 绑定恰为 2 处）；
   意向进入终态后随 10s 轮询自动解锁。
4. 写路径不变（仍 #28 的四键契约 POST），本 PR 纯读侧/展示层增量。

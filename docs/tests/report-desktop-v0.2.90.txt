desktop v0.2.90 — 规则文件:版本太旧直接说明 + 超时提示不再误导
================================================================================

来源:Vincent 2026-09-25 截图——一个 agent-node 版本已满足要求的节点读规则文件超时后,界面仍提示「需要 2.5.0-preview.58+」。

A. 版本不支持时立即说明(#347)
--------------------------------------------------------------------------------
  节点 agent-node 低于 2.5.0-preview.58(或 Claude Code 会话未上报支持)时,不发请求、不等 60 秒,
  直接显示节点当前版本与需要升级到的版本。

B. 超时文案改准(#347)
--------------------------------------------------------------------------------
  版本足够但 60 秒内没回应:提示节点没有来取这次请求,可能连接断开或卡住,重启节点通常能恢复——不再做版本判断。
  技能区超时文案同样去掉版本说法(技能区只对上报支持的节点出现)。

C. 验证边界(如实)
--------------------------------------------------------------------------------
  node-rules.test.ts 68/68(新增 22),6 种变异各自变红;npm test 123/123;tsc 205 = 基线。

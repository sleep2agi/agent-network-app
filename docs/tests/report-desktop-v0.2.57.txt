Desktop v0.2.57 release-candidate report

- Base: main after app#274 (desktop-v0.2.56)
- Target: desktop-v0.2.57
- Why: Vincent 2026-09-07 11:3x screenshot — the 0.2.56 workspace window ("Local workspace · 127.0.0.1:9201")
  shows 「无法连接服务器」 and 「Command plugin:http|fetch not allowed by ACL」.

Root cause
- Tauri capabilities are granted per window label. src-tauri/capabilities/default.json listed
  ["main", "chat-*"]; the new workspace windows are labelled workspace-<hash>, so every plugin command
  (http fetch, dialog, opener…) was denied inside them.

Changes
- capabilities/default.json windows += "workspace-*".
- desktop-chat-menu.test.ts: every window label minted by the app (main, chat-*, workspace-*) must be
  covered by the capability's windows patterns. Witnessed red with "workspace-*" removed, green restored.
- Bump to 0.2.57 (9 stamps + updater release notes). Hub pin unchanged (0.9.0-preview.45).

Evidence
- bun src/desktop-chat-menu.test.ts green; witness rc=1 without the grant; npm test + typecheck on PR;
  desktop-tauri.yml mac + windows dispatched on the branch (capabilities are compiled into the binary).

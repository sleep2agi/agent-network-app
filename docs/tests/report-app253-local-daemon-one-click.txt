app#253 — Local workspace: one-click scan/install of the local host_supervisor daemon (2026-09-06)

「本地的也可以自动启动 local 的 daemon 吧」→「不要自己启动的吧,有个一键扫描和安装按钮」.

What ships
- src-tauri/src/local_daemon.rs: scan() probes node/npm/anet through the user's login shell
  (GUI processes do not see nvm/homebrew PATH); install() = npm install -g (npmmirror fallback on
  registry-shaped failures, same signal list as docs-site/public/install.sh) → private-HOME
  ~/.anet/config.json with the local Hub's endpoint/utok/network_id → anet daemon init <name> --force
  (HOME=private) → anet daemon start <name> (real HOME, cwd ~/.anet/app/local-daemon) → poll
  /api/host-supervisors for the daemon_node_id (45 s). Tauri commands local_daemon_scan (sync) and
  local_daemon_install (async, spawn_blocking).
- src/local-daemon.ts + src/LocalDaemonSetupCard.tsx: checklist + blockers (no Node / old Node /
  no npm / unsupported platform / local Hub not running) + install button + step log.
  Mounted in HostSupervisorPickerScreen's count=0 state only for desktop + LOCAL_HUB_PROFILE_ID.
- Release gate: --smoke-local-daemon-install on macOS (runner has Node/npm): real npm install of
  anet, real host_supervisor registration against the packaged local Hub; then anet node stop.

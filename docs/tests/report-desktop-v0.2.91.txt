desktop v0.2.91 — 规则文件阅读模式:双击跳到对应源码行编辑
================================================================================

来源:Vincent 2026-09-25 需求——阅读模式下双击对应内容,跳到对应的 Markdown 位置进行编辑。

A. 双击跳转(#349)
--------------------------------------------------------------------------------
  阅读模式(内嵌与全屏)双击标题 / 段落 / 列表项 / 引用 / 代码块 / 表格行:切到编辑模式,
  选中该块对应的源码行并滚到编辑框中间;切回阅读时滚回光标所在块。
  偏移按编辑框自身文本计算(浏览器会把 CRLF 规范成 LF),不按节点原文,避免 CRLF 文件每行偏一个字符。
  聊天里的 Markdown 渲染不受影响(行号属性仅在规则文件阅读区开启)。

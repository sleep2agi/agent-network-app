- Base: main after app#300 (0.2.65 + quote replies)

Changes
- Quote replies (app#300): 引用 no longer pastes 「…」 into the draft; it pins a quote strip (author: text, ×)
  above the composer. The sent text is 「@author: text」 + body, so agents still receive plain readable
  context. Rendering splits that leading block out of the bubble into a one-line grey quote card under
  the bubble (sent: right-aligned; reply: left-aligned), matching WeChat. Legacy 「text」 quotes render too.
- Desktop right-click and mobile long-press selections now carry the author (sender alias / agent alias).
- Bump the desktop application consistently to 0.2.66 (9 pinned stamps + updater release notes).
- Bundled local Hub pin unchanged.

  desktop build after release.

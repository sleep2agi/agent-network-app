desktop v0.2.99 — 安卓应用内更新 + 项目文件夹文件树
================================================================================

A. 本版内容(0.2.98 版本号提交 #370 之后 main 上合入的全部 PR,共 2 个)
--------------------------------------------------------------------------------
  #371 安卓:设置里「检查更新」不再显示「当前环境不支持自动更新」。读取 GitHub releases/latest,
       下载 Agent.Network_<版本>_android-universal.apk(进度条、45 s 卡住看门狗、可续传、校验大小),
       用 content:// URI 交给系统安装器;被拦截时说明未知来源 / MIUI、HyperOS 安全守护,
       提供「重新安装」「去设置允许安装」「在浏览器中下载」。桌面端与 iOS 走原来的分支,不变。
       同时引入 android.versionCode = major*1000000 + minor*1000 + patch(本版 2099),
       version-consistency.test.ts 强制;android-build.yml 校验 versionCode、安装权限与签名证书。
  #372 节点「项目文件夹」右侧文件树:宽窗(内容列 ≥ 812px)并排、可拖宽 220–420px;窄窗 / 安卓双栏
       右栏为「目录」抽屉;按需列目录、按节点缓存、打开文件时祖先展开并高亮;手机布局不变。

Changes
- Bump the desktop application consistently to 0.2.56 (9 pinned stamps + updater release notes).
- Ship #273: one full workspace window per account ("新窗口" on every account row; /?workspace=<profileId>;
  label hashed from profileId so one window per account, re-click focuses; title "account · hub host ·
